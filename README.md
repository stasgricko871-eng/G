# RetroPad — Настраиваемый экранный ретро-геймпад поверх игр для Android

Полноценное приложение на Kotlin и Jetpack Compose для создания прозрачного игрового контроллера поверх других приложений, эмуляторов и портов игр в **горизонтальном (Landscape) режиме**.

---

## Временные текстуры (Placeholder) и как их заменить

В папке `app/src/main/res/drawable/` созданы готовые файлы текстур управления:
- `texture_dpad_cross.xml` — текстура крестовины D-Pad со стрелочками.
- `texture_joystick_base.xml` — основание (база) аналогового джойстика с кольцом и точками направлений.
- `texture_joystick_thumb.xml` — подвижный стик (грибок) джойстика.
- `texture_button_round.xml` — текстура круглой игровой кнопки действия (Z, X, C).
- `texture_arrow_up.xml`, `texture_arrow_down.xml`, `texture_arrow_left.xml`, `texture_arrow_right.xml` — текстуры отдельных стрелок.

### Как заменить на свои PNG или SVG:
1. Подготовьте свои изображения (например, `texture_dpad_cross.png` или `texture_joystick_thumb.png`).
2. Поместите их в папку `app/src/main/res/drawable/` с теми же именами (или замените содержимое соответствующих `.xml` векторных файлов).
3. Пересоберите проект — новые текстуры автоматически отобразятся на кнопках и стиках оверлея!

## Режимы управления: Стрелочки и Джойстик

1. **Режим стрелочек (D-Pad Cross):**
   - Классическая крестовина со стрелками `↑`, `↓`, `←`, `→`.
   - Мгновенный отклик, поддержка диагоналей (например, `↑` + `→`).
2. **Режим джойстика (Analog Joystick):**
   - Полноценный виртуальный аналоговый стик с плавным перемещением пальцем.
   - Зона нечувствительности (deadzone 20%) от случайных касаний.
   - Автоматический возврат стика в центр пружинной анимацией при отпускании пальца.
   - Перевод направления отклонения в `DPAD_UP`, `DPAD_DOWN`, `DPAD_LEFT`, `DPAD_RIGHT`.

Переключаться между стрелочками и джойстиком можно как через выбор готовых профилей (*Retro RPG (Стрелочки)* или *Retro Action (Джойстик)*), так и внутри редактора любой кнопки (селектор «Тип элемента: Кнопка / Стрелочки / Джойстик»).

## Важные замечания о безопасности Android и ограничениях API

### 1. Перехват Volume Up без изменения громкости мультимедиа
* **Официальный API:** Android запрещает обычным фоновым сервисам и окнам оверлея глобально перехватывать нажатия аппаратных клавиш других приложений.
* **Реализация:** В приложении реализована служба `VolumeKeyAccessibilityService`, использующая официальный Android API `AccessibilityService` с конфигурационным флагом `flagRequestFilterKeyEvents` (`canRequestFilterKeyEvents="true"`).
* **Поведение:**
  - При нажатии `Volume Up` (`ACTION_DOWN`, `repeatCount == 0`) сервис переключает видимость оверлея (Скрыть ↔ Показать) и возвращает `true`. Возврат `true` сообщает операционной системе Android, что событие клавиши полностью потреблено («consumed»), благодаря чему стандартный ползунок регулировки громкости **не всплывает**, а громкость мультимедиа **не увеличивается**.
  - При долгом удержании `Volume Up` многократное срабатывание отсекается проверкой `repeatCount == 0`.
  - Клавиша `Volume Down` возвращает `false` / `super.onKeyEvent(event)`, что сохраняет её штатную работу.
* **Ограничение платформы:** На некоторых вендорских прошивках с агрессивной оптимизацией фоновых процессов (MIUI/HyperOS, ColorOS) пользователю может потребоваться отключить оптимизацию батареи для приложения RetroPad.

### 2. Отправка клавиатурного ввода (KeyEvent) в сторонние игры
* **Модель безопасности Android:** Архитектура Android намеренно изолирует процессы приложений. Обычное стороннее приложение не имеет системных привилегий `INJECT_EVENTS` (требует системную подпись прошивки или root) для прямой инъекции произвольных `KeyEvent` в окно другой сторонней программы.
* **Целевое применение:**
  - Браузерные и HTML5/Canvas игры внутри WebView;
  - Игры и порты с открытым кодом, принимающие управление через локальные сокеты, виртуальные клавиатуры (IME) или внутри приложения;
  - Встроенный режим тестирования (экран «Тест управления»), демонстрирующий корректную обработку мультитача, одновременного удержания нескольких клавиш (например, `←` + `Z` или `↑` + `→`) и событий `KEY_DOWN` / `KEY_UP`.

## Инструкция по сборке и запуску

### В Android Studio:
1. Откройте проект в Android Studio (Ladybug / Iguana или новее).
2. Дождитесь завершения Gradle Sync.
3. Подключите устройство с Android 8.0+ (API 26+) или запустите эмулятор.
4. Выполните сборку: `Run 'app'`.

### Сборка через командную строку (Gradle):
```bash
gradle assembleDebug
```
APK-файл будет сгенерирован по пути:
`app/build/outputs/apk/debug/app-debug.apk`

---

## Первый запуск и настройка
1. Запустите приложение **RetroPad**.
2. В блоке «Статус системы» нажмите **«ВЫДАТЬ»** напротив *«Разрешение поверх приложений»* и включите переключатель в настройках Android.
3. Для работы переключения по кнопке Volume Up нажмите **«ВКЛЮЧИТЬ»** напротив *«Перехват Volume Up»* и активируйте службу RetroPad в меню «Специальные возможности» (Accessibility).
4. Нажмите **«ЗАПУСТИТЬ УПРАВЛЕНИЕ»**.
5. Нажмите физическую кнопку **Volume Up** — оверлей скроется. Нажмите ещё раз — оверлей снова отобразится.
